# EXPS Python Internship Projects

This repository contains all completed tasks for the Python Internship program.

## 📁 Repository Structure & Projects Summary

### 1. Hangman Game (`Hangman_Game.py`)
* **Description:** Text-based word guessing game using pre-defined word lists, hidden word display logic, and 6-attempt guess limiting.
* **Concepts:** `random`, `while` loops, `if-else`, string manipulation, list management.

### 2. Stock Portfolio Tracker (`Stock Portfolio Tracker/`)
* **Description:** Portfolio calculation tool using hardcoded stock prices that outputs a formatted report and exports it to both `.txt` and `.csv` files.
* **Concepts:** Dictionaries, Input/Output, Arithmetic Calculations, File Export.

### 3. Task Automation Scripts (`AUTOMATION/`)
All three automation task options have been implemented with High-DPI crisp Desktop GUIs using `tkinter`:
* **File Organizer (`File Organizer-Move .jpg files.py`):** Selects `.jpg` / `.jpeg` files with visual picker and moves them to a specified directory using `os` and `shutil`.
* **Email Extractor (`Email_Extractor.py`):** Uses Regular Expressions (`re`) to extract unique email addresses from `.txt` files and save them.
* **Web Title Scraper (`Web_Title_Scraper.py`):** Fetches web pages using `requests` and extracts `<title>` HTML tags using Regex.

### 4. Basic Chatbot (`Rule_Based_Chatbot.py`)
* **Description:** Interactive console rule-based chatbot with case-insensitive string processing and fallback intent detection.
* **Concepts:** `if-elif`, functions, loops, string normalization (`.lower()`, `.strip()`).
